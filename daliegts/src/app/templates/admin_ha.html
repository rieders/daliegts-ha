🏠 Home Assistant

„Hey, wo ist der Lötkolben?“ – Home Assistant fragt {{ APP_NAME }}, sagt dir den Lagerort und das Fach leuchtet über WLED auf. Die Blöcke unten einfach kopieren.

1. Token anlegen

Unter Mein Konto › API-Tokens ein Token „Home Assistant“ erstellen (am besten für einen eigenen Benutzer mit Lese-Rechten und „LEDs anzeigen“). In Home Assistant in die secrets.yaml:

lagerwerk_token: "Bearer lw_HIER_DAS_TOKEN"

2. Sätze festlegen

Datei config/custom_sentences/de/lagerwerk.yaml anlegen:

language: "de"
intents:
  LagerwerkWo:
    data:
      - sentences:
          - "wo (ist|sind|liegt|liegen) {was}"
          - "wo finde ich {was}"
          - "wo hab ich {was} hingelegt"
          - "(such|suche|finde) [mir] {was}"
lists:
  was:
    wildcard: true

3. Abfrage und Antwort

In die configuration.yaml:

rest_command:
  lagerwerk_wo:
    url: "{{ BASE_URL }}/api/v1/wo?q={{ '{{' }} was | urlencode {{ '}}' }}"
    method: GET
    headers:
      Authorization: !secret lagerwerk_token
    verify_ssl: false
    timeout: 10

intent_script:
  LagerwerkWo:
    action:
      - action: rest_command.lagerwerk_wo
        data:
          was: "{{ '{{' }} was {{ '}}' }}"
        response_variable: antwort
      - stop: ""
        response_variable: antwort
    speech:
      text: >-
        {{ '{%' }} if action_response.status == 200 {{ '%}' }}{{ '{{' }} action_response.content.speech {{ '}}' }}
        {{ '{%' }} else {{ '%}' }}{{ APP_NAME }} ist gerade nicht erreichbar.{{ '{%' }} endif {{ '%}' }}

Danach Home Assistant neu starten (oder „YAML neu laden“ für Intent-Script und REST-Befehle). verify_ssl: false ist nötig, weil {{ APP_NAME }} im Heimnetz ein eigenes Zertifikat nutzt.

Optional: Sensoren fürs Dashboard

Bestand unter Minimum, Einkaufsliste, Haltbarkeit und der 3D-Drucker (inkl. Warnung „Spule reicht nicht“) in einem Sensor:

rest:
  - resource: "{{ BASE_URL }}/api/v1/summary"
    headers:
      Authorization: !secret lagerwerk_token
    verify_ssl: false
    scan_interval: 300
    sensor:
      - name: "Lager unter Minimum"
        value_template: "{{ '{{' }} value_json.below_min {{ '}}' }}"
      - name: "Lager abgelaufen"
        value_template: "{{ '{{' }} value_json.expiry.expired {{ '}}' }}"
      - name: "3D-Drucker Hinweis"
        value_template: "{{ '{{' }} (value_json.printers3d | map(attribute='warning') | select | list | first) or 'ok' {{ '}}' }}"
